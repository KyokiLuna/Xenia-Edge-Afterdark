# HDD development milestone — 2026-11-18

This is an experimental Linux x86-64 milestone of Xenia Edge Afterdark. It
captures work in progress between V62 and the combined HDD gate. It is not the
finished HDD release. The AppImage, source archive, checksums and validation
records belong together; use the release's actual validation record when
assessing this particular build.

## Included work

- Shared folder-backed device, content and cache ownership, with space
  admission, mutation transactions and recovery checks.
- Profile discovery and persistence through registered storage devices,
  including conflict handling and profile-only deletion admission.
- Installed system-resource discovery and the SYSTEM media/font namespace.
- Native profile task scheduling, waiting, cancellation and lifetime work.
- Host-media references/import and shared content-library infrastructure.
- Existing Guide, notification, input capture and title-handoff corrections.

These changes have engineering tests. A passing unit test does not establish
that every dashboard, game or application consumer works.

## Launching and data

Native Guide/system UI is the milestone's default. A separate fallback launcher
is provided for comparison and recovery. Both use the same storage and profile
services; fallback mode does not complete native profile or avatar support.

Install your own compatible 2.0.17559.0 system files. No retail dashboard,
firmware, game, profile or Optional Media Update binaries are distributed.
The package must not depend on the developer's research directories.

Keep the accepted Guide and V62 packages. Start with the milestone's separate
data location or explicitly select backed-up existing Afterdark data. Do not
run two emulator processes against the same writable data. Follow the delivered
launcher and migration notes for the exact paths; do not reuse V62's old V59
data-pointer helper.

Before testing existing data, close Afterdark and preserve changed profile and
storage metadata. A metadata backup is not a complete backup of saves, games or
the entire library. Removing a host-media reference must leave its original
file intact.

## Known unfinished areas

- The full native profile-creation/sign-in/Avatar Editor path is still under
  investigation. Stock avatar rendering, editing and successful consumption
  by Doritos Crash Course have not passed the combined gate.
- Complete native media browsing, playback, seeking and Guide handoff remain
  unfinished. Native AAC additionally requires the Xbox 360 Optional Media
  Update, which is currently unavailable in the supplied test assets.
- The full two-device, interruption/recovery and dashboard-selector runtime
  matrix remains open. Engineering coverage is not a substitute for it.
- XNA runtime completion, the independent P2P social layer and online apps are
  later work. This milestone does not sign into Microsoft Xbox Live.
- MangoHud must remain disabled for performance comparisons on the test host.
  No BO1 frame-rate target or broad game-compatibility claim is made.
- macOS execution remains unverified.

Report the exact milestone identity, launch mode, action and log when testing.
Native sign-in loops, missing avatars and playback failures must remain recorded
as failures or prerequisites rather than reported as successful operations.

## Source and build provenance

The source upload preserves the existing GitHub README history and the original
Xenia/Xenia Canary/Xenia Edge attribution. The release records its exact source
commit, compiler and dependency revisions. This milestone may use the existing
incremental engineering build; the finished stable gate still requires a fresh
build with one compiler revision and its full acceptance matrix.

FFmpeg is pinned by the parent repository's submodule revision. The additional
Afterdark correction is distributed as
`third_party/patches/FFmpeg/xmaframes-overlap-tail.patch`, with complete source
hashes in its manifest. Run `python3 tools/research/apply_source_patches.py`
after initializing dependencies and before building. It accepts an already
corrected file and refuses unexpected source bytes.

GitHub-generated source archives omit submodule payloads. The release's source
instructions and dependency manifest describe how to obtain the exact pinned
dependencies; no dependency or locally modified source may be silently replaced
with a newer revision.

The combined HDD goal remains active after this milestone. A stable gate
release requires the mandatory storage, profile, avatar, media, library and
Guide scenarios to pass, plus a new upstream review and finished-AppImage tests.
