# HDD development checkpoint — 2026-11-23

This experimental Linux x86-64 checkpoint captures the current integrated
Afterdark work. The combined HDD gate is unfinished. It is a prerelease for
continued testing, not the stable finished-gate release.

## Integration included

- Shared storage/content/profile lifetime and persistence work since the
  2026-11-18 milestone, including retained content sources, request ownership,
  cache and teardown corrections.
- Native profile-picture request handling, installed-image decoding and 2D
  texture/frame ownership. These are shared services; their integration does
  not establish completion of native profile creation or 3D avatars.
- Persistent local console signing identity and local certificate/signature
  validation. This is Afterdark's own integrity path; it provides no Microsoft
  attestation or Xbox Live authentication.
- Native Avatar Editor caller/context handoff and a correction that performs
  the genuine avatar asset-size query while the original caller remains valid.
  Stock model rendering, editing and game consumption still require acceptance.
- Host locale teardown correction following a reproduced use-after-free.
  A subsequent strict sanitizer run did not reproduce that fault but failed
  on remaining library leaks. Sanitizer cleanliness is not claimed.

## Validation and remaining work

Use the delivered ACCEPTANCE.json, PROVENANCE.json and checksums to identify the
actual tested binary and runtime cases. Engineering tests and AppImage startup
checks do not establish the complete mandatory HDD runtime matrix.

Native account selection/profile creation, full native SAVE/GPD/container
publication, two-device operations and recovery, Avatar Editor persistence,
3D avatars in dashboard/Guide/Doritos Crash Course, and native media viewing,
playback, seeking and Guide handoff remain unfinished or unverified.
The Optional Media Update/CodecPack02 native AAC prerequisite is unavailable
in the current supplied assets. An external media player is not a replacement
for the Xbox 360's native media path.

This checkpoint adds no FPS guarantee and does not complete XNA or the direct
P2P Live replacement. MangoHud stays disabled. macOS execution is unverified.

## Launching and preserving data

Native system UI is enabled by default. The separate fallback launcher selects
Xenia's host UI while retaining the same shared storage/profile services.
Install your own compatible 2.0.17559.0 system update. Retail system files,
profiles, games and Optional Media Update binaries are not distributed.

The default checkpoint has its own data directory. Keep older releases and
original data available. Close Afterdark before any explicit existing-state
migration; two processes must never share writable state. Consult the release
bundle's launch/migration instructions for its exact supported paths.

The launcher disables core dumps and MangoHud and preserves a 20 GiB writable
filesystem reserve. Console signing payloads are private runtime state: keep
them out of source archives, public logs and bug-report bundles.

## Source, build and upstream accounting

The release source commit is an exact public snapshot of the qualified
first-party build inputs, including previously untracked implementation files.
It was created after compilation. The embedded version header retains the
actual build-base HEAD; provenance records both identities and the qualified
source hashes rather than attributing compilation to a later commit.

The source archive supplies pinned dependency revisions, an explicit restore
helper, and the actual FFmpeg/SDL source overlays. This is an incremental
engineering build; the finished stable gate still requires a fresh coherent
build and the complete mandatory runtime acceptance matrix.

Upstream patches are admitted only when they support Afterdark's console-level
goals. The eight newly reviewed commits through upstream
6841e1d66a142dcf8426b675800aa2715a7491a3 are deferred for this checkpoint:
the GPU accuracy changes require a combined regression check, and the JIT
leaf optimizations must account for Afterdark's backend-injected host calls.
The delivered upstream decision report gives each concrete decision. This
review does not claim closure of all older deferred changes; that accounting
remains required before the finished HDD gate release.
