# HDD source backup, 2026-11-25

This source-only backup preserves the integrated work through V122 and the
current system-contract research. It does not create an AppImage, alter the
existing release assets, or close the combined HDD gate.

## Integrated source and validation

The source includes the accumulated storage/profile persistence work, local
console-signing implementation, native UI/input and lifetime fixes, CPU module
retirement correction, native account flag corrections, and bounded original
logon/shutdown diagnostics. Console keys and runtime profile data are not source
artifacts and are excluded.

V121 ran the direct base, network, kernel, VFS and UI suites plus CPU and
installed-resource selections: 323/27,705; 125/11,212; 1,392/87,544;
136/9,736; 124/4,863; 5/130; and 65/11,545 cases/assertions respectively.
V122 changed two diagnostic implementation files, rebuilt app/kernel, and ran
65 installed-resource/profile/ABI cases with 11,545 assertions. Its other five
test products are unchanged; the broader V121 runs are historical.

The actual V122 native run rendered Guide, HDD selection and OSK, and created a
persistent local profile. Native sign-in returned E_ABORT before initializer
entry because the UI frame still owns its old-source read. Normal WM close
returned 1 at the in-flight-hook shutdown check; owned process cleanup finished
without signals. Avatar Editor, signed-in Guide and the full HDD acceptance
remain incomplete. The Guide slowdown is reported but its cause is unmeasured.
See the [detailed regression report](17559-checkpoint-guide-regression-20261123.md).
