decoded_dump master module index (v2)
=========================================
One record per file in the dump (relative to decoded_dump/,
mirrors the original 'Blades + NXE Classic/' layout).
Regenerate with: python3 _tool/build_01_modules.py

IMPORTANT - address space note:
  xex_load_address / xex_entry_va = XEX2 runtime virtual
    address space (xex2_security_info.load_address, and the
    XEX_HEADER_ENTRY_POINT optional header). THIS is the
    address space used everywhere else in this corpus
    (exports, imports, call graph, IPC map).
  pe_image_base / pe_entry_rva = the standalone PE32 header's
    own ImageBase/AddressOfEntryPoint, embedded inside the
    decoded body by the Xbox toolchain. These often equal the
    XEX values for un-relocated modules but are NOT guaranteed
    to and must never be assumed interchangeable.
  decoded_file_size = size of the file sitting in decoded_dump/.
  pe_size_of_image = the PE header's own SizeOfImage field.
  xex_security_image_size = xex2_security_info.image_size.
    These three sizes are DIFFERENT fields, recorded separately
    on purpose - do not assume they're equal.

Confidence: CONFIRMED (structurally parsed from headers) |
  INFERRED (derived/fallback value) | UNKNOWN (field absent) |
  UNRESOLVED (file still encrypted) | SUSPECT_METADATA (patch
  header reconstruction may be incomplete)
