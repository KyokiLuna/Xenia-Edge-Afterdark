Which decoded modules have parsed import-library tables
===========================================================
Regenerate with: python3 _tool/build_03_imports.py

Structural parse of each module's XEX_HEADER_IMPORT_LIBRARIES
optional header (xex2_import_library records). Each import is a
(variable_slot, thunk) pair sharing an ordinal - see
xenia-edge/src/xenia/cpu/xex_module.cc:SetupLibraryImports for the
original semantics this was reverse-engineered against (that's
Xenia's own loader code, so CONFIRMED, not guessed).

Names are resolved ONLY when the imported library is xam.xex,
xboxkrnl.exe, or xbdm.xex (Xenia ships ordinal->name databases
for those three). Imports of anything else (e.g. one dashboard
module importing from another) are ordinal-only - do not invent
names for them.
